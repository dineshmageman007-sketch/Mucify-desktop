    Welcome to Mucify

    Let's get you set up. It takes about a minute: a Soulseek login, an optional Qobuz connection, and Mucify takes care of the folders.

    Soulseek login

    Mucify downloads through Soulseek. Pick any username and password. If the name is free, Soulseek creates the account the first time you connect.

    Your Soulseek password is created for you when Mucify first opens, so there's nothing to look up. You can also roll a fresh username and password any time with the shuffle buttons.

    Qobuz (optional)

    Connecting Qobuz lets Mucify look up each track's official maximum quality. Without it, tracks simply default to 24-bit / 48 kHz.

    Your folders

    Mucify has prepared these for you. You can change them later in Settings.
